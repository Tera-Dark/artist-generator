## 本次检查补上的问题

1. 禁用 IndexedDB 时结果曾仍显示“已保存到历史”；现在等写入结果返回后区分**本地已保存**和**仅本次会话暂存**，收藏与编辑结果也有对应提示。
2. 直接删除本地记录缺乏误触保护；现在会先弹出确认，取消不会删除。
3. 备份接近容量上限时导出文件可能超过旧的 5 MB 导入限制；现在使用紧凑 JSON、**32 MB 有界导入**，并验证了超出旧限制的完整回环。编辑器也不会生成违反备份记录长度约束的内容。
4. 只读图片代理此前校验了初始目标，却未明确禁止上游 HTTP 跳转；现已拒绝跳转，并补充代理与可选部署函数的测试。
5. 加强了画师双份数据一致性测试及本地 `.env` / 个人导出备份的 Git 忽略规则。
